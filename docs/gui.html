DX-CAD documentation

The window

dxcad gui opens the viewer: an OpenCASCADE scene on the left, the model.py in a pane on the right, and the output of the last run under it. Everything the window does to a document is an edit that can be undone, and everything it builds it builds through the same kernel the command line uses.

The window is the one part of DX-CAD™ that needs a display. Every other command runs on a machine with none.

Opening it

On nothing, on a project, or on a model.py. These three are the whole of it:

dxcad examples bracket
dxcad run bracket.py --output bracket.dxcprt
dxcad gui
dxcad gui bracket.dxcprt
dxcad gui bracket.py

dxcad-gui opens the same window with no console behind it, which is what a desktop shortcut points at. Every command here is in cli.md.

A file that cannot be opened is never met with silence (item 803). Started on one, by any of these names or by a double click in Explorer, DX-CAD brings its window up with nothing open and a box that names the file, why it cannot be opened (it does not exist; it is not a DX-CAD project; for a STEP file that does not read, the STEP reader's own error) and what would work. The same words go to the log and the output pane, and the exit status is 2 once the window is shut. A STEP file is not opened as a project: dxcad import makes a project of it, and a model's import_step reads it. With a window already open, that window says it instead, once. If DX-CAD cannot start at all, a message box of the system's own says why in one line and where the log is.

When anything keeps the window busy for a second, a large drawing being drawn, a model being built, an add-on's command, a small "Please wait" window appears over it with what is being done, and stays a second after the work ends so it never blinks away; a command that takes under a second never shows it. While a model builds it has a Cancel button, which ends the run with the document as it was, as Stop on the status bar and Esc do.

A message too long for the status bar is cut with "...", and its whole text is kept: it is the bar's tooltip, and a click on the bar opens it in full in a small box with Copy and Close, so the end of a long refusal, what to do about it, is never lost. A message that fits has neither.

Work that knows its steps says how far it has got: drawing a sheet's views (view n of N) and exporting a drawing, each of its sheets' views a step. It shows a bar with the percent done and, once at least 5 percent is done and 5 seconds have passed, the time left ("About 3 minutes left": whole minutes above a minute, tens of seconds below). Work whose steps are not known, such as a model build, shows a moving bar and the time so far ("2 min 10 s so far"), never a made-up percent. An export can be cancelled too: Cancel stops it at its next view, no file is written, nothing is changed, and the status bar says "Cancelled: nothing was changed". Work that cannot stop shows no Cancel. The window stays the size it is whatever it says.

Tabs

Several documents can be open at once, one tab each (item 570). Each tab has its own parts, model pane, undo history and file name, and the Parts and History docks, the title bar and the actions follow the tab in front. The tabs show above the view once there are two; drag one to move it, and Ctrl+Tab and Ctrl+Shift+Tab step through them. The button at the tabs' right, or Window > Tile, shows them side by side instead. Closing the window asks once for each tab with unsaved changes. With a window open, dxcad gui FILE or a double click on a part, assembly or drawing file hands the file to that window as a tab. An agent over dxcad serve --window works on the tab in front, and each result names it.

The menus

One section per menu, in the order the menu bar has them, and one row per action. A shortcut is written as Qt writes it, so Ctrl+Shift+S on Windows and Linux is Cmd+Shift+S on a Mac; an action with no shortcut has an empty cell. The test suite reads the menu bar offscreen and holds this list to it, row for row.

The menus and toolbars follow the tab in front (item 856). A command that does not apply to it is greyed, not hidden, so the menus keep their shape, and the pointer over it says why: a Model or Sheet Metal command on a drawing's tab says "Open a part or assembly for Flange", a Drawing command on a part's says "Needs a drawing tab: open a drawing for Add View", and a Sketch tool with no sketch in progress "Start a sketch for Line". Files, Undo, Redo, Delete, Zoom Window, Measure, the panels, the window and Help apply on every tab. A command that applies but is greyed for want of something says what it needs, such as "Fuse: Needs two parts or more". An add-on's command is greyed the same way where it says it does not apply.

The panels

What each part of the window is, which is where F1 lands with the focus in it.

The 3D view

The document's parts, drawn by the OpenCASCADE viewer. A left drag orbits, a middle drag pans and the wheel zooms at the pointer; a click picks the part, face or edge under it, and Ctrl+click adds one to what is picked. File > Settings > Controls can make the middle button orbit instead. The view's right-click menu has the commands that act on what is picked. Fit, the seven views and the display modes are under View and on the View and Display toolbars.

The drawing sheet

A drawing tab shows its sheet in the view's place: the views, their sizes and labels, the title block and the parts list. A click selects a view and a drag moves it; the wheel zooms at the pointer and a middle drag pans, and View > Fit Sheet shows the whole sheet again. A right-click on a view or on the sheet has what can be changed there. With several sheets, the tabs along the bottom choose the one shown.

A view may be turned a quarter turn at a time about its own centre, which stays where it is: Rotate 90 Anticlockwise and Rotate 90 Clockwise on the view's right-click menu, or Rotation in Drawing properties, 0, 90, 180 or 270 degrees anticlockwise. Its lines, hidden lines, centre lines and sizes turn with it; a size says what it said before, and the words and the view's label stay level. Each turn is one undo step, and the drawing keeps it when saved. A top or right view turned is no longer kept in line with the front, as one unlocked; turning the front turns only the front.

Every text of the title block, a field's value and a cell's caption alike, can be dragged to another place on the sheet, as a view is; only the text dragged moves while the pointer does. Each drag is one undo step, the drawing keeps how far each text was moved when saved, and the sheet, the DXF and the PDF draw it there. Reset Text Positions, on the title block's right-click menu, puts every text back where the template has it, as one undo step.

The Parts list

The Parts dock, on the left: the document's parts in the model's order, a sub-assembly's parts under it. A click on a row picks the part and puts the model pane on its line, and the eye beside a row hides or shows the part. Under the list are the picked part's properties: its name, volume, size, material, mass and colour. View > Parts shows or hides the dock.

The History list

The History tab beside Parts: every edit the undo history holds, oldest first, the current one marked. A click on an earlier entry undoes back to it, and on a later one redoes to it. View > History shows or hides it.

The Feature Tree

Each part in the order the model builds it and, beneath it, its features, its sketches and its mates. A click on a row picks the part and puts the model pane on that row's line. Nothing in the tree is dragged or re-ordered. View > Feature Tree opens and closes it. A double click on a flange's row, or Edit Flange... on its right-click menu, opens the Flange dialog on that flange. A mate's row has Edit Mate... and Delete Mate on its right-click menu, and a double click on it opens the Edit Mate box; neither moves a row.

The Parameters form

The model's named values as a form (View > Parameters). Each top-level NAME = value line of the model pane is a field, under the model's own comment headings; the comment on its line gives its unit, its range (# mm, 1200..4000) or its choices (# paint | galvanised | powder, or # "flat" or "pitched"). A unit word anywhere in the comment is the value's, unless it follows another number (# under the 4 mm lid is the lid's); a range counts in brackets of its own, (1..17), or as a clause of its own, never inside a sentence; choices may be named on the indented comment lines just below the value. A tuple of numbers is a field per member, X_DOOR[0] and X_DOOR[1], and A, B = 80, 50 a field per name. Private names (a leading underscore), names DX-CAD gives every model, and tables holding text are left out. Type a value and press Enter, tick a box or pick a choice: only that value is written into the model, the model is rebuilt, and one Undo takes both back. A value out of its range, or not a number where one is wanted, is refused at the top of the form and on the status bar, and nothing changes. A value worked out from others is shown with its expression and cannot be typed into: change the values it is made from. The form holds no rules between values: it is the model's own values, nothing more. An agent reads and sets the same values with the get_parameters and set_parameter tools.

The output pane

Under the model pane: what the last run printed, and what a command refused and why. View > Output shows or hides it.

The Assistant

The Assistant dock, along the bottom of the view: type a request and the steps taken to build or change the document show in the chat, each one written into the model and one Undo. Stop ends a turn. View > Assistant, or Ctrl+Shift+A, shows or hides it, and File > Settings > Assistant chooses the provider and its model.

Each request carries model.py whole, as far as the provider has room for it: 200,000 characters to Claude (your own Anthropic key or the DX-CAD account), 100,000 to OpenAI, Azure OpenAI and Gemini, and 24,000 to an OpenAI-compatible endpoint, or two characters for each token of its Context size (tokens) in Settings > Assistant where you give it. A longer script is cut at the end of a line, and the request says after which line it was cut.

Drawing properties

While a drawing tab is in front, the left dock shows the sheet's size, its Title Block..., the parts list's columns and, for the view clicked on the sheet, its label, its scale and its hidden lines.

A new view's hidden lines are off: tick Hidden lines to show that view's, a view Add View put there as much as one of the sheet's four. Leave out small parts, with a size in mm, leaves the parts whose largest size is under it out of that view's lines only; the other views, the view's sizes and the parts list are as they were.

Centre marks under the sheet turns them on or off for the whole drawing, and Centre marks under the view clicked for that view alone, over the drawing's; each is one undo entry and the .dxcdrg keeps both. Text height is the height the drawing letters in: Sheet's own, 2.5, 3.5, 5 or 7 mm. The views' labels, the title block's fields, the dimensions and an add-on's annotations take it; the drawing's file keeps it, and a change is one undo step.

Each change is one undo step, the drawing's file keeps it and the DXF's DXCAD dimension style carries it. Each is then selected by a click, moved by its handle, edited by a double-click (a value typed over the one measured, which is marked as typed, and a tolerance after it; an empty value gives the measured one back) and taken off by Delete, one undo step each, nothing else on the sheet moving. Their values are measured from the model whenever the sheet is drawn, so a change of the model updates them; the drawing's file keeps them, and the PDF and DXF carry them. A drawing never asked draws as it did.

While one is chosen Angle and Bend radius are grey, since a hem has its own, and Teardrop radius is read for a teardrop alone; an open hem is still Angle 180 with Hem left at none.

All edges puts a flange on every free edge of the outline in one go. Ticked, a table opens under the fields with a row for each of those edges: the edge, then its Length, Length to, Angle, Direction, Bend radius, Return length, Start inset, End inset and Corners. Every row starts with the fields' values as they stood and is then its own; a number is typed in its cell and a choice made in its list. A row whose edge is unticked gets no flange. The flanges are made in the rows' order and are one undo step. A table's flanges take no relief, holes or cutouts: those are given to one flange, with the box unticked.

When a value is wrong the dialog says which edge, which value and why, as "Edge 2: Angle 200: an angle is above 0 and at most 180." When each value is right in itself but the flange would run into the part, it names the length to shorten, the return first and then the leg, and the longest that works there, which it finds by making the flange shorter.

Edit Flange changes a flange the model already has. Double-click the flange's row in the Feature tree, or right-click it and choose Edit Flange...: the dialog opens with the values the flange was written with, its edge kept. OK writes the flange() call again and builds the part from that flange on, everything made after it included, as one undo step. The view shows nothing of the edit until then. A flange whose values the model works out, from a variable or a loop, is changed in the model pane, which is put on its line; an edit after which a later step no longer builds is refused with that step's reason, and nothing changes.

The Base Flange dialog

Sheet Metal > Base Flange...: the material and a stocked gauge of it, or Custom with the thickness, the bend radius and the K-factor, for the sheet part made from the closed sketch in hand. Each number is checked as it is typed, and OK is enabled only when the part can be made.

The Check Interference box

Model > Check Interference...: the pairs of parts that overlap, each with the volume they share. The overlaps show in red in the view until the box is closed. "Also list pairs closer than [ ] mm", empty to begin with: type a gap and press Enter or List, and every pair that does not overlap and is nearer than that is listed after the overlaps, with its gap to three places and its two nearest points, and a red line is drawn between those points until the box is closed. Touching faces read 0.000. Empty, the box lists what it always did.

The Licences box

Help > Licences...: the third-party notices as this copy of DX-CAD ships them, every library it runs on with its version and licence, and the LGPL texts in full.

The Licence box

Help > Licence...: where this install's licence stands. Type a licence key and press Activate, or sign in with the email address the licence was bought with: Send code, then the six digits from the email and Sign in. Deactivate gives the seat back for another computer. The box shows the install id a seat is counted by.

Licences go on sale on 1 November 2026, or the day the release's latest.json names. Until that day, Activate, Send code and Sign in contact nothing: each says, in a box titled "Licences from 1 November 2026", that licences (a paid subscription) are available from that day, and that DX-CAD and its add-ons cost nothing until your trial ends. Until then the box and the trial's notices say "Licences are available from 1 November 2026." where they would give a link to buy one. The box says each date once: one line for DX-CAD's trial (the days left, its last day and the day editing and saving lock without a licence) and one for the add-ons, "Free during your 30-day trial (ends DATE)", which lock with editing unless a licence names them; it grows to show every line in full, also after an answer. Deactivate is greyed unless a licence is activated on this computer. When the licence service cannot be reached, it says only "DX-CAD could not reach the licence service. Check your internet connection and try again."; what went wrong is written to DX-CAD's log, with no key, code, email or token in it. latest.json may also name a day no trial ends before (its trial_until): a trial that would end sooner then locks at 23:59 UK time on that day, and the box and the notices say that day.

An activated licence is checked online at least every 14 days: at each start and every 8 hours while DX-CAD is open, the status bar saying "Checking the licence..." at a start that needs it until the answer comes. If it could not be (the computer offline that long, or the clock set back past the last check), the box, the status bar and the command line say "Your licence could not be checked online in the last 14 days", not that a trial has ended; the next start with the network back checks it again with nothing typed, and the key box holds the key last used, ready to activate again.

DX-CAD keeps the latest date and time it has seen on this computer, a moment and nothing else, and never moves it back. If the computer's clock is set more than a day before it and no licence is active, the box and the status bar say "The computer's clock is set earlier than the last time DX-CAD ran", with that day, and editing and saving wait until the clock is set right; opening, viewing and exporting still work. This keeps a clock set back from reopening a trial that has ended. It never locks before that day has really passed, so never during the trial, which lets everyone edit whatever the clock says, and never with a licence active, whose add-ons stay granted too; a clock that jumps more than two days ahead is not believed until a server's date agrees, so a clock set ahead by mistake and set right again locks nothing; and a server's date wins over the computer's. When DX-CAD has asked the network anyway (the update check, the licence service), it compares the computer's clock with the server's: more than an hour apart, the box says so ("Your computer's clock is 3 hours behind the server's"), and a server more than a day ahead counts as the latest time seen. Nothing locks on the gap alone.

An add-on's panel

A greyed command of an add-on that is not installed opens a short panel: the command, the add-on it belongs to and what the add-on adds, with a Buy button that opens the add-on's page in your browser. Nothing is run and nothing is sent.

The Add Part Sheets box

Drawing > Add Part Sheets...: the model's sub-assemblies and parts, each with a tick box, none ticked. Tick the ones that are to have a sheet of their own and press Make Sheets; Cancel adds nothing. The sheets are made five at a time, with a question after each five.

The search field above the list narrows it as you type: any part of the name, upper or lower case alike. A part the search hides keeps its tick, and gets its sheet. Tick all shown and Untick all shown tick or untick the parts listed and no other; "N ticked" beside Make Sheets counts every tick, shown or not. Enter in the search field does not make the sheets.

"Show the flat pattern on sheet metal parts' sheets", ticked at first, gives the sheet of each sheet metal part a fifth view, its flat pattern; with it off the sheets are made with their four views alone.

The recovery box

Shown at the start when DX-CAD did not close cleanly: the tabs that had changes not saved, each by its name and when it was kept. Recover opens every one as a tab with its changes, Discard throws them away, and Later leaves them for the next start.

The Settings dialog

The Keyboard Shortcuts box

The Suggest Mates box

Model > Suggest Mates...: the mates the picked part's features allow against the parts near it, best first. Picking a row shows where the part would go. Tick the ones to add and press Accept Checked, or Accept All; Cancel adds none.

The Import wizard

File > Import..., or Sketch > Import DXF...: a STEP file or a DXF drawing brought in in four steps, Back and Cancel on each. 1. The file: typed, or found with Browse...; its format is read from what it holds, not its name, so a DXF named .step is read as DXF. A DWG is refused, and Next stays off: DX-CAD does not read DWG yet, so save it as DXF from the program that made it. 2. Check, adding nothing: for STEP the units the file declares, its solids, shells and faces, the names and colours it carries, how many solids are valid, its open shells and its size, with a warning when it is under 1 mm or over 100 m across, which looks like a units mistake; for DXF its units, its layers with the lines, arcs and circles on each, the closed loops, what will be left out and its extents. 3. Place: STEP as one part or a part per solid, named from the file, its scale and the units to read it in where the file says the wrong ones; DXF on which plane, its scale and which layers. 4. Summary of what Finish adds. Finish writes it into the model (import_step, or the DXF's sketch as its own lines) and runs it, one step for Undo; Cancel adds nothing. After a DXF the window works in 2D drafting, and a STEP brought in while in 2D drafting turns it to 3D modelling; the status bar says so. Nothing is previewed: the parts appear after Finish.

The Edit Mate box

OK writes the new mate on the same line of the model and runs it, one step for Undo; Cancel changes nothing. There is no preview: the parts move after OK. The lines scroll; the font, the text height, OK and Cancel stay in view.

The model pane

The pane on the right is the model.py, and it is the document's source of truth: the shapes in the scene are what the last run of that text built. Typing in it changes nothing until the model is run.

  • Run Script, or F5, runs it. What it prints goes to the output pane, and a model that raises puts the cursor on the line that raised, with the helper file's own line above it when the failure was in a file beside the model.
  • Run on Change watches the model.py on disk, and its helpers, and runs the model again whenever one of them is saved. It is for an editor in another window: the pane follows the file rather than the other way round. It is off for every new window and is taken off again by New and by Open.
  • No Time Limit lifts the limit a run is given, a minute unless Settings > Runs sets another, from 5 s to an hour. A run happens on the window's own thread, so a model that never ends is a window that never answers again; the limit is there so that a typo costs a minute rather than everything typed since the last save. A run or a check the limit stops says so in one sentence, on the status line, in the output pane and in Copy Details alike ("Stopped at the 60 s time limit; Model > No Time Limit lifts it"), with no trace and no line of the model marked, and the document is as it was before the run. The tick is remembered from one session to the next, and stays through New, Open and a change of tab; an agent's run in the window is held to the same limit.
  • Check Model runs the model and says what it would change without changing anything, and Show in Script goes the other way, from a part in the scene to the line that built it.
  • Adopt Parts is for a document holding parts no model builds, which is what an older project looks like: it writes each of them to a file beside the project and adds the line that reads it back, so the model builds everything again.

The model a project carries

A part or assembly file is something people are sent, and the model inside one is a program. So a project opened from a file is asked about before its model is run for the first time, by Run, by F5 or by Run on Change: the question says that a model is Python and runs with your own permissions, and names the project. Answering no runs nothing and changes nothing. Answering yes runs it, and the window does not ask again until it is given another project.

A model you opened by name, one you typed into a new project and one the window wrote itself are your own and are never asked about.

Whether any of this looks right on a desktop is a manual check: the suite drives the window offscreen, where nothing is drawn. The scene itself, the orbiting and the picking, is the one part of DX-CAD no test can see.
